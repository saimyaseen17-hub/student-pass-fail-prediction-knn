Project Overview

This project predicts whether a student will pass or fail based on:

Attendance Percentage
Homework Percentage
Midterm Score
Study Hours Per Week

The model uses the K-Nearest Neighbors (KNN) classification algorithm.

Dataset Features
student_id
attendance_pct
homework_pct

study_hours_per_week
pass (Target)
